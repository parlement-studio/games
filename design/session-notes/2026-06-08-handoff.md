  pakai snapshot kode lama. Wajib **stop → start Play** untuk memuat perubahan.
  Verifikasi sync via `script_grep` (cek isi skrip di Studio) sebelum menyimpulkan.
- **`screen_capture` menangkap viewport EDITOR, bukan kamera Play.** Jangan
  pakai untuk verifikasi visual gameplay/kamera — pakai sampling terukur via
  `execute_luau` (baca properties), atau minta owner Play sendiri.

  (catch hold = 0.6s). Pakai `keyDown F` → `wait 900ms` → `keyUp F`.
- **Plugin require cache terpisah** dari game scripts — pakai BindableFunction
  bridge (mis. `PackCatchMint`, `DevAwardXp`) untuk baca state runtime.

  tembus; sekarang konstanta dikumpul di tabel `LY` (~142 top-level locals,
  ada headroom). Hati-hati saat menambah fitur UI besar lagi.
